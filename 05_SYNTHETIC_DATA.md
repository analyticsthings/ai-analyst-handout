# 🧪 Синтетические данные

Безопасный полигон для тренировки промптов и тестирования санитизации. Данные реалистичны по структуре, но полностью сгенерированы.

## 🛡 Правила
1. Никогда не заменяйте плейсхолдеры на реальные данные в этом репо
2. Для тестов используйте только файлы из этой папки
3. При расширении домена добавляйте новые сущности в `scenarios.json`
