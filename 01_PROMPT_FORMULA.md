# 🧩 Универсальная формула промпта

## 📐 Структура: `Роль + Контекст + Задача + Формат + Ограничения`

```text
[Роль] Ты <конкретная роль с уровнем и доменом>. 
Пример: "Ты Senior System Analyst в B2B-финтехе, знакомый с BABOK, REST API и внутренними гайдлайнами компании Х".

[Контекст] Что уже известно: домен, смежные системы, бизнес-правила, ограничения.
Пример: "Пользователи загружают .xlsx до 50 МБ. Система валидирует ИНН по алгоритму ФНС, сохраняет в S3."

[Задача] Один глагол + один объект. Конкретно и измеримо.
Пример: "Сгенерируй 3 User Stories с критериями приёмки для фильтрации истории загрузок."

[Формат] Как должен выглядеть результат.
Пример: "Каждая US в формате: Как <роль>, я хочу <действие>, чтобы <ценность>. AC: Given-When-Then."

[Ограничения] Чего делать НЕЛЬЗЯ. Что делать с неопределённостью.
Пример: "Не выдумывай поля БД. Нет данных → ставь [TBD]. Все даты — ISO 8601."

🔹 Для User Stories:
"Ты системный аналитик, специализирующийся на декомпозиции требований. 
Ты умеешь превращать размытые бизнес-«хотелки» в атомарные User Stories 
с тестируемыми критериями приёмки по формату Given-When-Then."

🔹 Для API-дизайна:
"Ты API-архитектор, знакомый с OpenAPI 3.1, REST-best practices и 
корпоративными стандартами компании Х. Ты проектируешь идемпотентные, 
версионируемые и документированные контракты."

🔹 Для моделирования процессов:
"Ты аналитик процессов, эксперт в BPMN 2.0 и state machines. 
Ты умеешь выявлять тупиковые состояния, описывать rollback-сценарии 
и связывать события с побочными эффектами в смежных системах."

🔹 Для валидации требований:
"Ты QA-ориентированный аналитик. Твоя задача — находить пробелы, 
противоречия и нефальсифицируемые формулировки в требованиях 
и предлагать конкретные уточнения."

# ⚡ Экспресс-проверка промпта
[ ] Роль указана конкретно (не "помощник", а "Senior SA в финтехе")?
[ ] Контекст содержит домен, правила и ограничения?
[ ] Задача сформулирована как "один глагол + один объект"?
[ ] Формат вывода явно задан (таблица, Gherkin, YAML, PlantUML)?
[ ] Ограничения включают запрет на выдумки и правило для [TBD]?
[ ] Все данные в промпте — синтетические или обезличенные?
