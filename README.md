## 🚀 Быстрый старт
1. Скачайте архив: `Code → Download ZIP`
2. Или форкните репо: `Use this template`
3. Запустите санитизацию: `python 03_SANITIZATION_SCRIPTS/sanitization.py`
4. Адаптируйте промпты под ваш стек
